# ⚡ Modular Showcase Engine (Cauê Systems)

Engine modular de alta conversão para criação rápida de vitrines digitais, landing pages e portfólios profissionais para prestadores de serviço e empresas locais (Marcenarias de Alto Padrão, Designers de Interiores, Arquitetos, Marmorarias, Clínicas, etc.).

Desenvolvido com princípios dos design systems **Nimbuu UI/UX** e **Impeccable Design System**.

---

## 🚀 Como Criar o Site de um Novo Cliente em 15 Minutos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/JesielSouza/modular-showcase-engine.git site-cliente-novo
   cd site-cliente-novo
   npm install
   ```

2. **Edite apenas o arquivo `src/site.config.js`:**
   - Troque o nome do cliente, cidade, WhatsApp e mensagem padrão;
   - Insira as fotos dos projetos e os serviços dele;
   - Escolha o layout do Hero (`split` ou `centered`).

3. **Suba para a Vercel:**
   ```bash
   vercel --prod
   ```

Pronto! O site estará no ar, otimizado para celulares, com botão flutuante de WhatsApp, SEO e tempo de carregamento instantâneo.
